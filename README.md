# Gerenciador de Empresas

## 1. Explicação do Projeto

O **Gerenciador de Empresas** é um sistema desenvolvido como trabalho prático da disciplina de Engenharia de Software, com o diferencial de ter seu frontend e backend construídos inteiramente com o auxílio de Inteligências Artificiais.

O sistema tem como objetivo permitir o gerenciamento de empresas, oferecendo funcionalidades como:

- Cadastro, edição e exclusão de empresas
- Cadastro e gerenciamento de usuários
- Controle de permissões de acesso
- Visualização de informações cadastrais em painel administrativo

- **Docker** — containerização da aplicação

## 5. Histórias de Usuário

1. **Cadastrar empresa** — Como administrador, eu gostaria de cadastrar uma nova empresa informando razão social, CNPJ, endereço e contato, para que ela passe a fazer parte da base do sistema.
2. **Editar empresa** — Como administrador, eu gostaria de editar os dados de uma empresa já cadastrada, para corrigir informações erradas ou desatualizadas.
3. **Excluir empresa** — Como administrador, eu gostaria de excluir uma empresa que não é mais gerenciada, para manter a base limpa e sem registros obsoletos.
4. **Listar e pesquisar empresas** — Como usuário do sistema, eu gostaria de listar as empresas cadastradas e pesquisá-las por nome ou CNPJ, para localizar rapidamente a que preciso.
5. **Visualizar detalhes de uma empresa** — Como usuário do sistema, eu gostaria de abrir a ficha completa de uma empresa, para consultar todos os seus dados cadastrais em uma única tela.
6. **Cadastrar usuários** — Como administrador, eu gostaria de cadastrar novos usuários informando nome, e-mail e senha, para dar acesso ao sistema a novas pessoas.
7. **Controlar permissões de acesso** — Como administrador, eu gostaria de definir o perfil de cada usuário (administrador ou usuário comum), para que cada um só execute as operações permitidas ao seu perfil.
8. **Autenticar-se no sistema** — Como usuário cadastrado, eu gostaria de fazer login e logout com e-mail e senha, para acessar o painel de forma segura.
